# Table for One

My project is a web based online ordering and kitchen inventory system for a small, family owned restaurant. Customers can browse the menu and place pickup or delivery orders from the restaurant's own website instead of third party delivery apps. Every order, whether it comes from the website, the phone, or the counter, shows up on one kitchen display in the order it was received. As orders are completed, ingredient stock is reduced automatically and the manager is alerted when an item is running low. The owner also gets simple sales reports to see best selling items and busy hours.
